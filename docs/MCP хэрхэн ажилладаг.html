MCP нь AI-г MACS Human Capital-тай хэрхэн холбодог вэ

MCP (Model Context Protocol) нь AI апп өөр системийн хэрэгслүүдийг олж мэдэж, ашиглах стандарт арга юм. Манай сервер хоёрхон хэрэгсэлтэй: describe_data ба run_query. Хэн ч асуусан зөвхөн тухайн хэрэглэгчид харах эрхтэй HR өгөгдлийг л авна. Доорх жишээнд «Одоо хэдэн ажилтан ажиллаж байна вэ?» гэж асууж байна.


      

    

  


  
  

    
Өөр систем (Claude, өөрийн бот, MACS ERP-ийн өөр модуль) энэ серверт ердийн HTTP хаяг ба токеноор холбогдоно. Тусгай програм суулгах шаардлагагүй. Холбогч бүр өөрийн токентой бөгөөд токен нэг HR хэрэглэгчид хамаарна.


    

      
      
    


    

    

      

        
Холбогдохын тулд юу хэрэгтэй вэ

        

          
1. ХаягНэг машин дээр http://127.0.0.1:8765/mcp. Гаднаас бол туннель эсвэл HTTPS прокси-ийн нийтийн нэр, жишээ нь https://mcp.example.com/mcp.

          
2. ТокенАдмин дахь «MCP хандалт» → «MCP токенууд» дээр холбогч бүрт нэг токен үүсгэнэ. Токеныг зөвхөн нэг удаа харуулна. Токен нь сонгосон HR хэрэглэгчийн эрхээр ажиллана.

          
3. Хост жагсаалтГаднаас холбогдох бол нийтийн нэрийг .env дахь MCP_ALLOWED_HOSTS-д нэмж серверийг дахин асаана. Нэмээгүй бол сервер HTTP 421 буцаана.

          
4. АсаалтСервер анхнаасаа унтраастай. .env-д MCP_ENABLED=true тавьж python manage.py run_mcp ажиллуулна.

        

      


      

        AХамгийн энгийн шалгалт: curl›
        

          
Токенгүй дуудвал 401 ирнэ. Энэ нь сервер ажиллаж, токенгүй хүсэлтийг татгалзаж байгааг харуулна.


# токенгүй: 401 ирэх ёстой
curl -i -X POST http://127.0.0.1:8765/mcp

# токентой: хэрэгслийн жагсаалт
curl -s http://127.0.0.1:8765/mcp \
  -H "Authorization: Bearer mhc_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

          
Сервер төлөвгүй (stateless) тул «initialize» дуудлага заавал хийх шаардлагагүй. Ямар ч MCP клиент өөрөө энэ дарааллыг хийдэг.

        

      


      

        BMCP дэмждэг AI апп (Claude гэх мэт)›
        

          
Аппын тохиргоонд «алсын MCP сервер» нэмж URL болон Authorization: Bearer толгойг оруулна. Тохиргооны талбар, цэс нь апп бүрт өөр байна.


URL:           https://mcp.example.com/mcp
Header:        Authorization: Bearer mhc_xxxxxxxx
Transport:     Streamable HTTP

          
Шалгаагүй: бодит AI апптай (Claude Desktop, MCP Inspector) холбож үзээгүй байна. Тухайн апп «Bearer токен» толгойг дэмждэг эсэхийг эхлээд шалгана. Зарим апп зөвхөн OAuth дэмждэг бөгөөд манайд OAuth одоогоор байхгүй.

        

      


      

        CӨөрийн код, бот эсвэл өөр MACS систем›
        

          
Албан ёсны MCP SDK (Python, TypeScript болон бусад) нь Streamable HTTP клиенттэй. Хаяг ба токеныг өгөөд describe_data, дараа нь run_query-г дуудна. Протоколын хэсгийг SDK хариуцна.


# Python SDK-ийн төрлийн жишээ (хэлбэр нь хувилбараас хамаарч өөр байж болно)
async with streamablehttp_client(
        "https://mcp.example.com/mcp",
        headers={"Authorization": "Bearer mhc_xxxxxxxx"}) as (r, w, _):
    async with ClientSession(r, w) as session:
        await session.initialize()
        await session.call_tool("describe_data", {})
        await session.call_tool("run_query", {"sql": "SELECT ..."})

          
Жишээ нь зөвхөн ойлголтыг харуулна, ажиллуулж шалгаагүй. Энэ бол үндсэн санаа: өөр MACS систем бидний API-г биш, энэ стандарт хаалгыг дуудна.

        

      


      

        DГаднаас хэрхэн хүрэх вэ›
        

          
Сервер анхнаасаа зөвхөн 127.0.0.1-д сонсдог тул зөвхөн нэг машин доторх програм хүрнэ. Гаднаас хүрэхэд хоёр сонголт бий. Хоёулаа токенийг орлохгүй, токен хүсэлт бүрт шаардлагатай хэвээр.

          

            
Сонголт A: гарах туннель (cloudflared)Харилцагчийн машин гадагш холболт нээнэ, галт ханад порт нээх шаардлагагүй.

            
Сонголт B: HTTPS проксиIIS, Nginx, Caddy гэх мэт одоо байгаа вэб серверээр 127.0.0.1:8765 руу дамжуулна.

          

          
Шалгаагүй: cloudflared болон прокси-ийн жишээнүүд баримтад бий (docs/mcp-deployment.md, 6-р хэсэг). Харилцагчийн машин дээр туршиж үзээгүй. Төвлөрсөн MACS гарц (gateway) хараахан бүтээгдээгүй.

        

      

    

  


  
  

    

      
      
    

    
    

    

  


  
  

    
Манайд бүтээгдсэн таван хэсэг, тэдгээрийн тусдаа багц болсон хуваалт, одоогоор хийгээгүй зүйлс. Тус бүрийг нээж үзнэ үү. sqlcore ба sqlmcp нь тусдаа macs-sql-mcp багцад, hr_sql ба hr_mcp нь HR-ийн app/ хавтас дотор байна.


    

      1Хяналттай SQL (sqlcore багцад, hr_sql HR-д)›
      

        
Цөм нь AI-д өгөх өгөгдлийг хязгаарладаг. AI зөвхөн GOV_ гэж нэрлэгдсэн харагдацуудыг (GOV_EMPLOYEES, GOV_LEAVE, GOV_ORDERS, GOV_SALARY гэх мэт) SELECT-ээр уншина. Асуулт бүрийн өмнө тухайн хэрэглэгчид харагдах ажилтны жагсаалтыг түр хүснэгтэнд (GOV_SCOPE) бөглөж, дараа нь гүйлгээг үргэлж буцаана (rollback).

        

          
ХязгаарХамгийн ихдээ 1000 мөр, 15 секундийн хугацаа, SQL 4000 тэмдэгтээс хэтрэхгүй.

          
ТатгалзахDELETE зэрэг SELECT биш асуулт, жагсаалтад байхгүй хүснэгт нь татгалзагдана. Татгалзал нь алдааны тэмдэгтэй (isError) хариу болж буцна.

        

      

    


    

      2MCP сервер (sqlmcp, багцад)›
      

        
Протоколын хэсэг: Streamable HTTP-ээр /mcp дээр хоёр хэрэгслийг (describe_data, run_query) нийтэлнэ. Төлөвгүй, JSON хариутай, токены шалгалттай. Django болон HR кодыг оруулдаггүй тул өөр MACS системд дахин ашиглахад бэлэн.

        
Эхний дүрэмAI эхлээд describe_data дуудаж, юу асууж болохыг мэдэж байж run_query бичнэ. Сервер өөрөө үүнийг заавал шаардахгүй, зөвхөн зааварт бичсэн.

      

    


    

      3Токен ба хэрэглэгч (hr_mcp)›
      

        
Токен бүр нэг HR хэрэглэгчид хамаарна (mhc_ угтвартай). Систем зөвхөн токеныхоо хэш-ийг хадгална, токеныг өөрийг нь хэзээ ч хадгалдаггүй. Токеныг админаас үүсгэж цуцлана, зөвхөн суперхэрэглэгч үздэг. Цуцлагдсан эсвэл идэвхгүй хэрэглэгчийн токен ажиллахаа болино.

        
АнхаарТокен тус бүрт тусдаа эрх байхгүй. Эрх нь токены хэрэглэгчийн эрхтэй адил. Холбогч бүрт зөвхөн хэрэгтэй эрхтэй тусдаа хэрэглэгч сонго.

      

    


    

      4Хамгаалалт ба түүх›
      

        

          
Хурдны хязгаарТокен бүр минутанд 30 дуудлага (MCP_RATE_PER_MINUTE). Татгалзсан дуудлага мөн тоологдоно.

          
Хост шалгалтЗөвхөн жагсаалтад байгаа хаягаар ирсэн хүсэлтийг хүлээн авна (MCP_ALLOWED_HOSTS), эс бол 421.

          
Дуудлагын түүхДуудлага бүр (татгалзсан ч) хэрэгслийн нэр, SQL, мөрийн тоо, хугацаатай бичигдэнэ. SQL нэр агуулж болох тул нууц гэж үз.

          
ЦэвэрлэгээТүүхийг автоматаар устгахгүй, хэр удаан хадгалахыг шийдээгүй.

        

      

    


    

      5Асаах, ажиллуулах›
      

        
Сервер Django сайтаас тусдаа програм бөгөөд анхнаасаа унтраастай. Тохиргоо нь .env файлд.


MCP_ENABLED=true
MCP_BIND_HOST=127.0.0.1
MCP_BIND_PORT=8765
MCP_RATE_PER_MINUTE=30
MCP_ALLOWED_HOSTS=127.0.0.1:*,localhost:*

python manage.py run_mcp

        
Дэлгэрэнгүй: docs/mcp-deployment.md.

      

    


    

      6Тусдаа багц ба бусад MACS систем›
      

        
sqlcore ба sqlmcp нь HR-ийн кодоос тусдаа macs-sql-mcp багц болсон (хувилбар 1.0.0, хувийн GitHub репозитор ochroo0705/MacsMCP). Django болон HR-ийн код оруулдаггүй. HR үүнийг requirements.txt-д git tag-аар тогтоож (@v1.0.0) суулгана.

        

          
HR-д үлдсэнhr_sql (GOV_ харагдац, GOV_SCOPE), hr_mcp (токен, түүх, хурдны хязгаар, админ) болон HR-ийн хэрэгслийн текст (hr_mcp/text.py).

          
Өөр систем юу өгөх вэӨөрийн host (ямар харагдац, хэрэглэгчийн эрхээр хэрхэн ажиллуулах), токен шалгах функц, хүсвэл дуудлагын hook, мөн өөрийн зааврын текст.

        

        
Чухал: багц зөвхөн «нэг унших SELECT, жагсаалтад байгаа харагдацууд» гэдгийг шалгана. Хэн ямар мөрийг харах эрхтэйг host шийднэ (HR-д GOV_SCOPE). Харагдац нь хэрэглэгчээр хязгаарлагдаагүй системд зөв асуулт ч харах эрхгүй мөрийг буцааж болно.

        
Багцыг өөрчлөхдөө тусдаа репозитор дотор засаж, тестлээд, шинэ tag тавьж, HR-ийн requirements.txt дахь tag-ийг солиод дахин суулгана. Хувилбар 1 нь зөвхөн Firebird. Багцын репозиторт README, төрлийн тэмдэглэгээ (py.typed), токены анхдагч хадгалалт одоогоор байхгүй. Жишээ: багцын examples/minimal_host.py.
