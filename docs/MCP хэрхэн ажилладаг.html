MCP хэрхэн ажилладаг

MCP нь AI-г таны системтэй хэрхэн холбодог вэ

MCP (Model Context Protocol) нь AI апп өөр системийн хэрэгслүүдийг олж мэдэж, ашиглах стандарт арга юм. Доорх жишээнд HR системээс ажилтан хэдэн өдрийн амралт үлдсэнийг асууж байна.


      

    

  


  
  

    

      
      
    

    
    

    

  


  
  

    
AI аппыг системтэй ажиллуулахад таван зүйл хэрэгтэй. Тус бүрийг нээж үзнэ үү. Эхнийх нь таны одоо байгаа систем, дундах гурав нь таны бүтээх хэсэг.


    

      1Гаднаас дуудаж болох систем›
      

        
AI зөвхөн таны систем гаднаас зөвшөөрдөг зүйлийг хийж чадна: REST API, өгөгдлийн сангийн холболт эсвэл кодын функц. Хүн дэлгэц дээр дарж байж л хийдэг зүйл бол эхлээд API хэрэгтэй.

        
ШалгахСкрипт аппыг нээлгүйгээр амралтын үлдэгдлийг уншиж чадах уу?

      

    


    

      2MCP сервер (адаптер)›
      

        
Таны хэрэгслүүдийг жагсаадаг жижиг програм. Хэрэгсэл бүр нэр, энгийн хэлээр бичсэн тайлбар, авах оролтуудтай. AI загвар юуг дуудахаа эдгээр тайлбараас уншиж шийддэг тул загварт зориулж бичнэ. Албан ёсны SDK-ууд (Python, TypeScript, C#, Java болон бусад) протоколыг хариуцна, та зөвхөн хэрэгслийн биеийг бичнэ.


from mcp.server.fastmcp import FastMCP
mcp = FastMCP("hr")

@mcp.tool()
def get_leave_balance(employee: str) -> str:
    """Ажилтны үлдсэн ээлжийн амралтын өдөр."""
    row = hr_api.get("/leave/balance", employee=employee)
    return f"{employee}: {row['days_left']} өдөр үлдсэн"

mcp.run()  # stdio, эсвэл transport="streamable-http"

        
Зөвхөн жишээ: docstring нь хэрэгслийн тайлбар, type hint нь оролтын схем болно.

      

    


    

      3Холбогдох арга (transport)›
      

        

          
stdio (дотоод)AI апп таны серверийг нэг компьютер дээр өөрөө ажиллуулж, шууд харилцана. Энгийн, сүлжээ шаардахгүй, нэг хүний компьютерт тохиромжтой.

          
Streamable HTTP (алсын)Сервер сүлжээнд URL хаягтай ажиллана. Олон хэрэглэгч хуваалцана. HTTPS болон нэвтрэлт шаардлагатай.

        

      

    


    

      4Эрх ба аюулгүй байдал›
      

        
Сервер бол цорын ганц хаалга. Хэн асууж буйг (API түлхүүр эсвэл OAuth нэвтрэлт) мэдэж, тухайн хүнд зөвшөөрөгдсөн зүйлийг л буцааж, дуудлагуудыг бүртгэж байх ёстой. Өгөгдөл өөрчилдөг хэрэгслийг (амралт батлах, бичлэг устгах) зөвхөн унших хэрэгслээс тусад нь тэмдэглэж, ажиллуулахаас өмнө хэрэглэгчээс баталгаажуулалт авна.

        
Эхний дүрэмЗөвхөн унших хэрэгслээс эхэл. Бичих хэрэгслийг дараа нь нэг нэгээр нэм.

      

    


    

      5MCP дэмждэг AI апп›
      

        
Host апп (дэлгэцийн туслах, IDE, чат бүтээгдэхүүн эсвэл SDK-аар бүтээсэн өөрийн агент) дотроо MCP клиенттэй. Та серверийн байршлыг, өөрөөр хэлбэл ажиллуулах тушаал эсвэл URL-ыг зааж өгнө. Үүнээс хойш олж мэдэх, дуудах ажлыг клиент хариуцна.

        
{
  "mcpServers": {
    "hr": { "command": "python", "args": ["hr_server.py"] }
  }
}

        
Ердийн тохиргооны хэлбэр. Файлын байршил, талбарууд аппаас хамаарч өөр байна.
